# SPEC section 12 asks for a bundled static list rather than a network lookup, so
# signup never depends on a third party being up. Lines starting with # and blank
# lines are ignored; everything else is lowercased and matched against the domain
# part of the address.
#
# This is deliberately a short, high-confidence list of the throwaway services
# people actually reach for, not an exhaustive mirror of one of the 100k-entry
# GitHub lists. A long list is mostly dead domains plus a steady trickle of false
# positives against small real providers, and it is the false positives that cost
# a real user their account. Add a domain here when one shows up in the signup
# logs; the loader fails open, so a mistake in this file cannot take signup down.
